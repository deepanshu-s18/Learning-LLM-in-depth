# DeepSeek From Scratch - Beginner Friendly

A clean, beginner-friendly from-scratch implementation of the DeepSeek architecture in PyTorch.

## Chapters

| Chapter | Topic |
|---------|-------|
| ch01 | Introduction to DeepSeek |
| ch02 | KV Cache Bottleneck |
| ch03 | Multi-Head Latent Attention (MLA) |
| ch04 | Mixture-of-Experts (MoE) |
| ch05 | Multi-Token Prediction and FP8 |
| ch06 | Training Pipeline |
| ch07 | Post-Training: SFT and RL (GRPO) |
| ch08 | Knowledge Distillation |

## Getting Started

```bash
pip install torch numpy
python ch06/01_main-chapter-code/model.py
```
